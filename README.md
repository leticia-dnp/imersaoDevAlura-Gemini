🧠 DataSense AI: Buscador de Ferramentas de Inteligência Artificial.
O DataSense AI é um catálogo web interativo desenvolvido para facilitar a busca e a descoberta das melhores ferramentas de Inteligência Artificial (IA), atendendo a acadêmicos, profissionais e entusiastas.

✨ Funcionalidades chave
- Catálogo Interativo: Exibe IAs fundamentais (Aprendizado de Máquina, Visão Computacional, etc.) em cards informativos e responsivos, carregados via data.json.
- Busca Dinâmica: Permite a filtragem em tempo real das IAs por nome, descrição ou tags na página principal (index.html).
- Identificação Rápida: Cada card destaca o custo (Gratuito / Pago) e as tags de categoria para uma identificação imediata.
- Lista de IAs Populares: Inclui uma página secundária (lista-ias.html) com um catálogo adicional de IAs populares do mercado (e.g., ChatGPT, Gemini, Copilot), exibidas em formato de lista simplificada.

💻 Tecnologias utilizadas:
O projeto utiliza uma arquitetura de frontend simples e de fácil manutenção:
- HTML5:	Estrutura semântica das páginas.
- CSS3:	Estilização moderna, responsividade e uso de CSS Variables (:root)
- JavaScript:	Lógica de busca, filtragem em tempo real e manipulação do DOM.
- JSON: Armazenamento estruturado dos dados das IAs listadas.
